# Muhammad Shahzaib — Portfolio

Personal portfolio website for **Muhammad Shahzaib**, Full Stack Developer
(React · Next.js · Node.js · Laravel), based in Rawalpindi / Islamabad, Pakistan.

Built with **React 18 + Vite**, styled with **Tailwind CSS v4**, animated with
**Framer Motion**, icons from **lucide-react**.

## Sections

- Sticky glass navbar with mobile menu and scroll-spy
- Hero with typewriter role animation, CTAs, social links and animated stat counters
- Tech marquee strip
- About with info cards
- Skills grouped by domain + services
- Experience vertical timeline
- Projects — large feature cards for JobPilot & GlamMart with **Live Demo** and **GitHub** buttons, grid for the rest
- Testimonials
- Dark contact section (info cards + mailto form)
- Footer with quick links and back-to-top

## SEO

- Keyword-rich title, meta description, keywords, author, robots, canonical URL
- Open Graph + Twitter card tags, theme-color, SVG favicon
- JSON-LD `Person` structured data
- `robots.txt` + `sitemap.xml` in `public/`
- Semantic HTML (single `h1`, header/main/section/footer), aria labels, skip-to-content link

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build   # outputs to dist/
```

## Deploying to Vercel

1. Push this folder to a GitHub repository
2. Import the repo in Vercel (framework preset: **Vite**)
3. Deploy — no environment variables needed
